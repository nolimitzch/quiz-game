# NBA Quiz Game

A quiz game I built in Python using Thonny. It asks 10 NBA questions,
tells you instantly if you're right, and saves your high score.

  <img width="641" height="322" alt="NBA quiz game running in Thonny" src="https://github.com/user-attachments/assets/5649d406-64d9-4f13-941c-4db1bc470b20" />


## How to run
1. Install Python from python.org
2. Download quizloop.py
3. Run it: python quizloop.py

## What I learned
- Using lists and loops to ask many questions
- Using if/else to check answers
- Saving and loading a high score from a file
- Fixing bugs like indentation and capital letters
